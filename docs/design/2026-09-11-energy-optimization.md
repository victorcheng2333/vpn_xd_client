# 三端后台耗电优化：实现与验证

本轮依据 [耗电调研](../research/2026-09-11-xd-vpn-energy.md) 减少无效后台工作。改动针对诊断与质量观察，不调整 DPD、DTLS、认证、自动恢复预算、TUN 路由或包转发。研究报告保留优化前的源码基线，本说明记录本轮实现。

## 最终行为

| 平台 | 优化前 | 本轮实现 |
| --- | --- | --- |
| iOS | 扩展每 5 秒写诊断，页面查询也写诊断 | 约 60 秒检查一次变化，允许 5 秒调度容差；内容不变不写。关键事件与最终计数立即保存，页面查询直接获取当前快照 |
| Android | 服务存活时每 5 秒请求统计 | 只有连接质量页处于 STARTED 且隧道已连接时每 5 秒采样；进入页面立即采样，离开、后台、恢复或停止时撤销调度 |
| macOS | App 存活期间每 30 秒扫描质量历史 | 新事件立即计算，只为历史的下一次窗口边界安排单次任务；无历史或全部过期后无后台扫描任务 |

iOS 定时器从实际执行时间重排，避免容差使下一次执行距上次写入不足 60 秒而跳过一轮。诊断的 `updatedAt` 表示观测时间，不作为连接心跳；IPC 的实时观察不会改变最后一次成功持久化的基准。写入失败保留后续重试资格，关键事件保存不会推迟下次常规检查。停止、失败及旧会话计时器都有状态或会话保护。

iOS App 优先使用 IPC，避免每次先被较旧的磁盘计数覆盖。3 秒无回复时使用缓存；同次请求的有效迟到回复仍可更新缓存，缓存不能反过来覆盖实时结果。新请求及会话身份、连接时间、系统状态共同防止迟到响应倒灌。若 IPC 持续超过页面 5 秒刷新周期，旧请求会失效，页面显示带观测时间的磁盘缓存；这是诊断降级，不驱动连接或重连。

Android 观察需求采用独立令牌和引用计数，订阅不启动服务、不启用自动连接、不保留 Activity。调度器限制为一个待执行任务，已取消回调和已销毁服务不能重新建立循环。引擎替换后立即采样新引擎，实际请求前再次检查观察需求、连接状态和引擎身份。UI 和分享报告区分“尚未采样”与最近一次缓存，后台缓存不宣称是最终流量。

macOS 到期安排同时考虑事件进入窗口、10 分钟告警窗口及 24 小时历史上下文；后者会影响恢复 episode 去重和异常退出告警。边界后 1 秒重算，保留原有包含边界的规则，并为执行留出 1 秒容差。时钟调整、唤醒时重新计算；退出取消任务与时钟观察。质量页可见时自身的 30 秒显示刷新保留。

## 回归验证

| 检查 | 结果 |
| --- | --- |
| macOS 全量 `bash scripts/test.sh` | 230 项通过；含连接、切网、恢复、停止、网络清理与权限通信 |
| macOS arm64 开发包 | Release 优化编译、图标封装、ad-hoc 签名与严格签名验证通过 |
| iOS `Apps/iOS/scripts/test.sh` | 135 项通过；含配置、路由、恢复、持久化失败重试与 IPC 请求竞态 |
| iOS 模拟器、iphoneos SDK 构建 | App 与 Packet Tunnel Extension 均通过，无签名安装操作 |
| Android JVM 测试 | 24 项通过，其中 8 项新统计订阅和调度测试 |
| Android lint、Debug / Release APK、R8 | 通过；双 ABI 的 ELF 与 ZIP 16 KB 对齐检查通过 |
| Android 专用 API 36 arm64 模拟器 | 19 项 instrumentation 全部通过，含新增页面生命周期与缓存语义测试；测试后已关闭 |

Mac 完整测试初次在沙箱中受本地 socket、系统网络只读访问限制；在获准访问的环境重跑同一套测试后全部通过。iOS 真机 SDK 构建的本地 Xcode 服务限制、Mac 图标封装的沙箱限制也经批准后通过。

新增用例重点覆盖：没有观察者时没有周期请求；重复订阅、旋转重叠及重复释放；引擎替换和已出队旧回调；停止后不复活；关键状态及时保存及失败后重试；实时数据不被缓存覆盖；没有新事件时告警仍可产生或解除；24 小时恢复上下文到期。

Android 的设备测试使用仓库专用 AVD 的隔离副本、合成凭据和仅监听本机的测试网关，未触碰真实手机或生产网关。详见 [Android 验证记录](../../Apps/Android/ENERGY-VERIFICATION-2026-09-11.md)。独立源码复查未发现阻塞问题。

本地构建产物（未安装/发布）：

- macOS：`build/energy-macos-arm64.app`（development 渠道，ad-hoc 签名）。
- iOS：`Apps/iOS/.build/xcode-iphoneos/Build/Products/Debug-iphoneos/XDVPN.app`（未签名）及独立模拟器产物。
- Android：`Apps/Android/app/build/outputs/apk/debug/app-debug.apk` 与 `release/app-release.apk`；签名与复现见 Android 验证记录。

## 验收边界

2026-09-11 用户通过 Xcode 真机运行后，已对 iOS 后台扩展补充 130 秒文件活动验证：仅 2 次诊断原子发布，间隔 65.012391 秒，确认高频诊断写入已修复。运行 UUID 与优化构建匹配；额外观察到桥接背压，需与采集扰动分开验证。详见 [iOS 真机验证](../../Apps/iOS/ENERGY-DEVICE-VERIFICATION-2026-09-11.md)。

这些测试验证代码与状态机行为，不等同于真机节电比例。实际增量功率、锁屏隔夜、蜂窝及真实网关切网稳定性仍应按调研中的同机 A/B 矩阵验收。没有改变生产网络参数，也未覆盖安装到用户的 Mac 或手机。

本轮不将“周期调用减少”换算为“电池节省百分比”。后续只有在真机测量显示收益且连接可靠性达标时，再评估保活间隔、DTLS 重试和批量转发。

# XD VPN Windows 0.1.4

Windows x64 预览版。下载安装 EXE，按提示授予管理员权限；ZIP 提供手动安装方式。升级前退出已运行的 XD VPN。

- 修复自包含 .NET 运行目录导致 PowerShell 动态编译失败、VPN 无法连接的问题，网络检查改用预编译组件。
- 修复安装授权、文件校验及失败回滚流程，配置应用和安装包图标。
- 改善断线恢复、进程退出、路由清理和连接状态反馈。
- 正常连接时的标题、状态和说明与 macOS 对齐；验证未完成或配置异常仍显示对应提示。

构建包含核心状态机、服务、路由脚本、安装器、UI、IPC 和引擎生命周期回归测试。安装器尚未配置代码签名，Windows 可能显示发行者未知；Wintun 驱动使用官方签名版本。

EXE、ZIP 的 SHA-256 校验值见附带的 `.sha256` 文件。
